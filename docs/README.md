# German Household Waste Classification Project

## Project Overview
This project focuses on applying machine learning and computer vision techniques to classify daily household waste into strict German recycling categories (*Gelber Sack*, *Restmüll*, *Papier*, *Bioabfall*, *Altglas*).

## Project Structure
- `data/`: Dataset documentation and references.
- `docs/`: Project documentation, business understanding, and sprint roadmaps.
- `src/`: Source code for feature extraction, baseline models, and CNN architectures.

## Environment & Tools
- Version Control: GitHub linked with Jira.
- Framework: Python, OpenCV, TensorFlow/PyTorch, Scikit-learn.
