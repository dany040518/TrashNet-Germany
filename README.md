# TrashNet-Germany
## Datasets
1. TACO Dataset:  https://github.com/pedropro/TACO o https://datasetninja.com/taco
- Content: Images captured in real-world environments (streets, indoor spaces, and natural settings), featuring instance-level segmentation annotations of waste.
- Project Application: Essential for waste detection, classification, segmentation, and image retrieval tasks. Since it contains real-world images with complex and noisy backgrounds, it allows us to evaluate the model's robustness under realistic conditions.
2. TrashNet Dataset: https://github.com/garythung/trashnetContenido
- Content: 2,527 images categorized into six classes: glass, paper, cardboard, plastic, metal, and trash. All images were photographed against a plain, light-colored background.
- Project Application: Facilitates the manual extraction of features required by traditional machine learning methods (such as kNN and SVM), since these algorithms cannot directly process raw images without appropriate preprocessing.

3. Waste Classification Dataset (Kaggle): https://www.kaggle.com/datasets/techsash/waste-classification-dataContenido
- Content: More than 25,000 photographic images divided into two main categories: organic waste and recyclable materials.
- Project Application: Provides the large volume of data needed to reduce the risk of project failure due to insufficient or unsuitable data (not having enough data or not having the right data).
